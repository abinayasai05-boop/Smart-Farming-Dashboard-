🌱 Smart Farming Dashboard

Description

A simple and responsive Smart Farming Dashboard built using HTML and CSS. It helps farmers monitor weather conditions, soil moisture, crop health, and farm status through an attractive user interface with animations.

Live webpage 
https://abinayasai05-boop.github.io/Smart-Farming-Dashboard-/
Features

- Weather Monitoring
- Soil Moisture Indicator
- Crop Health Status
- Farm Status Tracking
- Responsive Design
- CSS Animations

Technologies Used

- HTML5
- CSS3

Files

- "index.html"
- "style.css"

How to Run

1. Download the project files.
2. Open "index.html" in any web browser.
3. Explore the dashboard.
